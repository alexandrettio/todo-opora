## Выполнено

- Django system check: без замечаний.
- Миграции созданы и применены; незаписанных изменений моделей нет.
- 36 доменных, API- и интеграционных тестов: успешно.
- Проверены граница дня 05:00 и начало недели, переносы, предварительное планирование, повторное открытие, закрытие дерева, обязательные причины, история унаследованного планирования и прошлых недель.
- Проверены изоляция пользователей, CSRF при входе и валидация API.

- TypeScript и production-сборка Vite: успешно.
- Конфигурация Docker Compose проверена командой `docker compose config --quiet` с временными примерными настройками. Файл настроек после проверки удалён.
- Ручная проверка через браузер: вход, новая мысль, создание проекта из мысли, следующий шаг внутри проекта, включение проекта в неделю с наследованием, назначение задачи на день и секцию, выполнение с комментарием, форма обязательной причины снятия недельного обязательства.
- Проверены компоновки шириной 1360 и 390 пикселей; на мобильной ширине горизонтального переполнения нет.

Браузерная проверка использовала отдельную тестовую базу за пределами проекта. Демонстрационные записи и учётная запись не включены в поставку.

## Что требует проверки на сервере владельца

- Реальный запуск контейнеров с PostgreSQL, Gunicorn и Caddy: Docker-служба на текущем компьютере не запущена.
- Получение HTTPS-сертификата для домена и внешняя доступность приложения.
- Реальный OAuth и синхронизация Google: необходимы Google Cloud-проект, клиентские настройки и согласие владельца календарей.
- Создание и восстановление резервной копии в серверном окружении.

Локальные тесты базы выполнялись на SQLite. Проверка PostgreSQL, конкурентных транзакций и резервного восстановления входит в приёмку серверного развёртывания.

  Дополнительно пройдена строгая проверка TypeScript на неиспользуемые импорты,
